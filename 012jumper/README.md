# ホップ・ステップ・キャッチ！

モンスターをジャンプで避けながらダイヤを集めて走り続ける、スマートフォン向けのエンドレスランアクションゲームです。  
店舗コードに応じたプレイヤー画像の出し分け、集めたダイヤに応じた店舗おすすめメニューの提案機能（`menu.json` 連携）、Google Apps Script（GAS）へのプレイログ送信機能を備えています。

## フォルダ構成

```text
├── index.html       … ゲーム本体（Canvas描画・物理演算・スコア計算・ログ送信）
├── menu.json        … 店舗別のおすすめメニュー設定ファイル（ダイヤ集計と連動）
├── assets/          … 効果音（SE）フォルダ
│   ├── jump.mp3     … ジャンプ音
│   ├── gem.mp3      … ダイヤ獲得音
│   └── hit.mp3      … 衝突・ゲームオーバー音
└── image/           … ゲーム内で使用する画像アセット
    ├── logo.webp        … タイトルロゴ画像
    ├── 000000.png       … デフォルトプレイヤー画像
    ├── [店舗CD].png     … 店舗別オリジナルプレイヤー画像
    ├── dia_r.png        … 赤ダイヤ
    ├── dia_y.png        … 黄ダイヤ
    ├── dia_pr.png       … 紫ダイヤ
    ├── dia_g.png        … 緑ダイヤ
    ├── dia_b.png        … 青ダイヤ
    ├── dia_p.png        … ピンクダイヤ
    └── monster_1.png〜6.png … 障害物モンスター画像（計6種）
```

## 主な機能と仕組み

- **2段ジャンプ対応ランゲームアクション**
  - タップ、画面クリック、スペースキー等でジャンプします。
  - 空中で再度タップすることで「2段ジャンプ」が可能です。
  - プレイ中は画面下部に丸型「JUMP」ボタンが表示され、片手親指でのタップ操作にも対応しています。

- **URLハッシュによるプレイヤー画像動的切り替え**
  - URL末尾のハッシュ（例: `index.html#123456`）から店舗コードを取得し、該当する `image/123456.png` をプレイヤーキャラクターとして読み込みます。
  - ハッシュ未指定または画像が存在しない場合は、デフォルト画像 `image/000000.png` へ自動フォールバックします。

- **ダイヤ収集と店舗メニュー連携（menu.json）**
  - ゲーム中に6色（赤・黄・紫・緑・青・ピンク）のダイヤが出現します。
  - ゲームオーバー時、獲得数が一番多かったダイヤの色に対応する店舗メニュー（`menu.json` 内のデータ）が「あなたへのおすすめ」として画像付きカード形式で表示されます。
  - ダイヤ未獲得時は全メニューからランダムに1品が選出されます。

- **GASアクセス解析・スコアログ送信**
  - ゲーム開始時、リトライ時、およびゲームオーバー時に、走行距離（m）や総ダイヤ獲得数を含めたログをGoogle Apps Script（GAS）へ送信します。

- **自己ベスト記録保存（ローカルストレージ）**
  - 走行距離（m）とダイヤボーナスを合算したスコアが計算され、過去最高スコア（ベスト記録）は端末の `localStorage` に自動保存されます。

## よくあるカスタマイズ

| やりたいこと | 編集箇所 / 手順 |
| :--- | :--- |
| **プレイヤー画像を追加・変更する** | `image/` 内に `000000.png` や `店舗コード.png` を配置 |
| **おすすめメニューを変更する** | `menu.json` の該当店舗コード配下のメニュー名・画像URLを編集 |
| **障害物（モンスター）の画像・種類を変える** | `image/monster_*.png` を差し替え、`monsterDefs` 配列のサイズ設定を調整 |
| **タイトルロゴ画像を変える** | `image/logo.webp` を同じファイル名で差し替える |
| **ジャンプ力や重力、落下速度を変える** | スクリプト上部の `GRAVITY`（重力）や `JUMP_V`（ジャンプ初速）の数値を調整 |
| **効果音（SE）を変更する** | `assets/jump.mp3`, `assets/gem.mp3`, `assets/hit.mp3` を差し替える |

## 注意事項

- **音声ファイル（assets/*.mp3）の準備**
  - 本ゲームは外部SEファイル（`assets/` フォルダ配下の `jump.mp3`, `gem.mp3`, `hit.mp3`）を参照します。配置されていない場合、コンソールに読み込みエラーが表示されます。
- **menu.json のCORS制限**
  - `menu.json` を `fetch()` で読み込んでいるため、PC上でHTMLファイルを直接ダブルクリック（`file://`）すると読み込みに失敗します。動作確認は **GitHub Pages** やローカルWebサーバー上で行ってください。
- **画面比率について**
  - 縦型スマホ（幅最大520px）に最適化されています。PCブラウザでも横幅が自動制限され、スマホ比率のステージ枠内で描画されます。
