# 相性占い（Affinity Fortune）

2人の名前を入力してハートの鼓動演出とともに相性を診断する、スマートフォン向けWebゲームです。

## フォルダ構成

```text
├── index.html   … ゲーム本体（UI・アニメーション・音声・翻訳データ）
└── image/       … ゲーム内で使用する画像アセット
    ├── background.png   … 背景画像
    ├── player_left.png  … 左側のキャラクター
    ├── player_right.png … 右側のキャラクター
    ├── heart_idle.png   … 通常時のハート
    ├── heart_beat.png   … ドキドキ中のハート
    ├── cloud.png        … 背景に流れる雲
    └── star.png         … 紙吹雪の星パーティクル

## 主な機能と仕組み

- **相性スコア計算 (`calculateAffinity`)**
  - 入力された「名前1 + 名前2 + 今日の日付」からハッシュ値を計算します。
  - 同じ組み合わせ・同じ日であれば**何度占っても同じ結果**が出ます。
  - 日付が変わるとスコアも変わるため、「今日の相性」として楽しめます。
  - スコアは常に **60%〜100%** のポジティブな結果になります。

- **多言語対応（6言語）**
  - ブラウザの言語設定に応じて自動切り替え（日本語 / 英語 / 中国語 / 韓国語 / スペイン語 / ポルトガル語）。
  - 各テキストは `index.html` 内の `<script id="dc-ui-texts">` で管理されています。

- **フォールバック機能**
  - 画像の読み込みに失敗してもゲームがクラッシュせず継続します。
  - ネット回線等の都合でロードが終わらない場合も、5秒経過で自動的に入力画面へ遷移します。

---

## よくあるカスタマイズ

| やりたいこと | 編集箇所 / 手順 |
| :--- | :--- |
| **キャラクターや背景を変える** | `image/` 内の該当する画像を同じファイル名で差し替える |
| **文言や翻訳テキストを変える** | `index.html` 内の `<script id="dc-ui-texts">` の各言語JSONを編集 |
| **演出の時間を変える** | `index.html` の `gameState === 'DOKIDOKI'` 内の `duration`（現在5000ms）を編集 |
| **スコアの計算範囲を変える** | `calculateAffinity` 関数末尾の `Math.abs(hash % 41) + 60` を調整 |
