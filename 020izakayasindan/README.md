# メニュー性格診断

いくつかの質問に答えることで、自分の性格を居酒屋のメニューに例えて診断できるスマートフォン向けWebコンテンツです。  
個人診断の結果から、テーブルにいるメンバー全員の診断結果を合算する「2人用相性診断」「3人以上グループ診断」へ展開でき、店舗コードに応じたおすすめメニューの注文促進（プロモーション表示）まで一連の流れで楽しめます。

## フォルダ構成

```text
├── index.html          … 診断本体（UI・質問進行・個人/ペア/グループ診断ロジック）
├── data.json           … 質問データおよび共通の性格タイプ解説データ
├── stores.json         … 店舗コード別のメニュー名マッピングデータ（★店舗ごとに編集）
└── images/             … 画像アセットフォルダ
    ├── top.webp        … トップ画面のメインビジュアル画像
    ├── 000000/         … デフォルト店舗用のメニュー画像フォルダ（01.webp 〜 12.webp）
    └── [店舗CD]/       … URLハッシュの店舗コードに対応した個別メニュー画像フォルダ（任意）
```
