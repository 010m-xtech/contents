# あそび場

店舗などでの待ち時間にミニゲームを提供するためのスマートフォン向けポータルサイトです。  
店舗コードに応じたゲーム一覧の切り替えや、Google Apps Script（GAS）へのアクセス解析ログ送信に対応しています。

## フォルダ構成

```text
├── index.html       … ポータル画面本体（レイアウト・ログ送信・動的読み込み）
├── config.json      … 店舗ごとの配信ゲーム設定ファイル（★ここを編集してゲームを追加・変更）
└── thumbnail/       … 各ゲームのサムネイル画像を置くフォルダ
    └── default_game1.webp … 読み込み失敗時のデフォルトサムネイル
```

## 主な機能と仕組み

- **店舗コード（6桁）の自動判定**
  - URLの末尾（ハッシュ）から6桁の店舗コードを取得します（例: `https://example.com/#123456` → 店舗コード `123456`）。
  - ハッシュがない場合や該当店舗の設定がない場合は、デフォルト店舗コード `000000` のゲーム一覧が表示されます。
  - 各ゲームへのリンク先にも同じハッシュ（`#店舗コード`）が自動で引き継がれます。

- **config.json による動的配信**
  - `config.json` を書き換えるだけで、HTMLを触らずにゲームの追加・入れ替え・店舗別出し分けが可能です。

- **GASアクセスログ送信**
  - 「ページを開いたとき（閲覧）」および「ゲームのカードをタップしたとき（選択）」に、GASのエンドポイントへアクセスログ（店舗コード、端末ID、アクション名）を送信します。

- **サムネイルのフォールバック**
  - 指定した画像が見つからない、または読み込みに失敗した場合、自動的に `thumbnail/default_game1.webp` が代替表示されます。

## 設定ファイル（config.json）の書き方

店舗コード（6桁）ごとに表示したいゲームの配列を定義します。

```json
{
  "000000": [
    {
      "title": "あいしょう占い",
      "url": "[https://example.com/fortune/](https://example.com/fortune/)",
      "thumbnail": "thumbnail/fortune.webp"
    },
    {
      "title": "お酒診断",
      "url": "[https://example.com/sakesindan/](https://example.com/sakesindan/)",
      "thumbnail": "thumbnail/sake.webp"
    }
  ],
  "123456": [
    {
      "title": "あいしょう占い",
      "url": "[https://example.com/fortune/](https://example.com/fortune/)",
      "thumbnail": "thumbnail/fortune.webp"
    }
  ]
}
```

- `title`: ゲームの名前（ログ送信時の識別名にも使用されます）
- `url`: ゲームページの遷移先URL
- `thumbnail`: サムネイル画像のファイルパス（アスペクト比 `572:1024` 推奨）

## よくあるカスタマイズ

| やりたいこと | 編集箇所 / 手順 |
| :--- | :--- |
| **表示するゲームを追加・変更する** | `config.json` の該当店舗コード内の配列にオブジェクトを追加・編集 |
| **サムネイル画像を追加・変更する** | `thumbnail/` フォルダに画像を配置し、`config.json` の `"thumbnail"` パスを指定 |
| **見出しや説明文を変える** | `index.html` 内の `<header>` にある `<h1>` や `<p>` のテキストを編集 |
| **ログ送信先のGASを変更する** | `index.html` 内の `const GAS_URL = "..."` を新しいウェブアプリURLに差し替え |
| **カードの並び（列数）を変える** | `index.html` 内の `.game-grid` の `grid-template-columns` を編集 |

## 注意事項

- **ローカル環境（PC直接ダブルクリック）での注意**
  - `index.html` をブラウザで直接開く（`file://` プロトコル）と、ブラウザのセキュリティ制限（CORS）により `config.json` の読み込みに失敗して「コンテンツの読み込みに失敗しました」と表示されます。
  - 必ず **GitHub Pages** や、VS Code の「Live Server」などの Web サーバー経由で動作確認を行ってください。
- **JSONの構文エラー**
  - `config.json` を編集する際、末尾のカンマ（`, `）の付け忘れや付けすぎ、文字列をダブルクォーテーション（`"`）以外で囲むミスに注意してください。構文エラーがあると全カードが表示されなくなります。
