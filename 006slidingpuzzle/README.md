# スライドパズル（Slide Puzzle）

隣り合うピースをタップして動かし、絵を完成させるスマートフォン向けのWebスライドパズルゲームです。  
店舗コードやIDに応じた画像の動的読み込み、難易度（3×3 / 4×4）の切り替え、クリアタイム計測機能を備えています。

## フォルダ構成

```text
├── index.html       … ゲーム本体（UI・パズル計算・タイマー・画像動的読み込み）
└── photo/           … パズルで使用する画像を置くフォルダ
    ├── 000000.png   … デフォルト画像（ハッシュ未指定時や画像未検出時に使用）
    └── [ID].png     … URLハッシュのIDに対応した個別画像（.jpg / .webp も可）
```
## 主な機能と仕組み

- **URLハッシュによる画像の動的切り替え**
  - URL末尾のハッシュ（例: `index.html#123456`）からIDを取得し、`photo/123456.png` などの対応画像を自動で読み込みます。
  - ハッシュが指定されていない場合や画像が存在しない場合は、デフォルト画像 `photo/000000.png` が使用されます。
  - ポータルサイト（`game.url#店舗CD`）から遷移してきた場合、店舗ごとのオリジナル画像でそのままパズルを遊ぶことができます。

- **画像の拡張子自動探索 (`findExistingImage`)**
  - IDに対して `.png` → `.jpg` → `.jpeg` → `.webp` の順で存在確認を行い、見つかった形式の画像を自動採用します。

- **難易度切り替え（初級 / 上級）**
  - **初級 (3×3)**: 8ピース + 空きマス1（シャッフル回数: 100回）
  - **上級 (4×4)**: 15ピース + 空きマス1（シャッフル回数: 200回）
  - 解けない配置（詰み）が発生しないよう、完成状態から有効な手のみをランダムに動かしてシャッフルしています。

- **タイム計測 & 完成図ガイド**
  - シャッフル開始と同時にストップウォッチがスタートし、クリアまでのタイム（分:秒）を計測します。
  - 左下に完成図のサムネイルが常時表示されます。

- **クリア判定と演出**
  - 全ピースが正しい位置に揃うとタイマーが停止し、抜けていた右下の空きマスにも画像が補完されて一枚絵が完成したのち、クリアパネルが表示されます。

## よくあるカスタマイズ

| やりたいこと | 編集箇所 / 手順 |
| :--- | :--- |
| **デフォルト画像を変更する** | `photo/000000.png` を同じファイル名で差し替える |
| **特定店舗・用途の画像を追加する** | `photo/` フォルダ内に `店舗コード.png`（または `.jpg` / `.webp`）を配置する |
| **完成図サムネイルのサイズを変える** | `index.html` の `.sample-image` の `width` / `height` を変更 |
| **パズルの外枠サイズを変える** | `index.html` の `#puzzle-container` の `width` / `height`（現在360px）および `.piece` の `background-size`（現在352px）を調整 |
| **クリア演出の文言を変える** | `index.html` 内の `<div class="clear-panel">` にある `<h2>` や `<p>` のテキストを編集 |

---

## 注意事項

- **画像の縦横比について**
  - パズル枠は正方形（352px × 352px）でピースに分割して表示するため、配置する画像は **正方形（1:1）** を推奨します。長方形の画像を使用すると縦横比が歪んで引き伸ばされる場合があります。
- **ローカル環境での動作確認**
  - `index.html` をパソコンのブラウザで直接開く（`file://` プロトコル）と、`findExistingImage` 内の画像存在チェックがセキュリティ制限により動作しない場合があります。
  - 動作確認は **GitHub Pages** やローカルWebサーバー環境で行ってください。
