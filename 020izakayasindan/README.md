# メニュー性格診断

いくつかの質問に答えることで、自分の性格を居酒屋のメニューに例えて診断できるスマートフォン向けWebコンテンツです。  
個人診断の結果から、テーブルにいるメンバー全員の診断結果を合算する「2人用相性診断」「3人以上グループ診断」へ展開でき、店舗コードに応じたおすすめメニューの注文促進（プロモーション表示）まで一連の流れで楽しめます。

## フォルダ構成

```text
├── index.html          … 診断本体（UI・質問進行・個人/ペア/グループ診断ロジック）
├── data.json           … 質問データおよび共通の性格タイプ解説データ
├── stores.json         … 店舗コード別のメニュー名マッピングデータ（★店舗ごとに編集）
└── images/             … 画像アセットフォルダ
    ├── top.webp        … トップ画面のメインビジュアル画像
    ├── 000000/         … デフォルト店舗用のメニュー画像フォルダ（01.webp 〜 12.webp）
    └── [店舗CD]/       … URLハッシュの店舗コードに対応した個別メニュー画像フォルダ（任意）
```
## 主な機能と仕組み

- **URLハッシュによる店舗別メニュー＆画像の動的切り替え**
  - URL末尾のハッシュ（例: `index.html#123456`）から6桁の店舗コードを取得します。
  - `stores.json` に該当店舗のメニューが定義されていればそのメニュー名を表示し、未指定・未登録の場合はデフォルト店舗 `000000` が自動適用されます。
  - メニュー画像は `images/[店舗CD]/[メニューID].webp` を読み込み、個別画像が存在しない場合は `images/000000/[メニューID].webp` へ自動フォールバックします。

- **個人性格診断（メニュー診断）**
  - `data.json` に定義された質問に回答し、各選択肢に紐づくタイプ別スコアを加算して最もスコアの高いメニュー（同点時はランダム抽選）を結果として表示します。
  - 結果画面にはメニュー画像・キャッチコピー・性格解説のほか、テーブルでの注文を促すプロモーション枠が表示されます。

- **テーブルメンバー合算（ペア診断 ＆ グループ診断）**
  - 個人診断後に「今日のグループ診断を作成」からテーブル上の各メニューの人数を入力できます（自分の結果は初期値1名として自動セット）。
  - **2名の場合（ペア診断）**: 2人の相性度（%アニメーション表示）、関係性分析、ワンポイントアドバイスを表示します。
  - **3名以上の場合（グループ診断）**: メンバーの構成比率（熱血・安定・マイペース系）に応じて宴会コース名・チームワーク度・リーダー役・ムードメーカー・ベスト相性コンビ・取扱説明書を自動生成します。

## 設定ファイル（data.json / stores.json）の書き方

### 1. `data.json`（質問と性格タイプのベースデータ）
質問リスト（`questions`）と、ID `"01"`〜`"12"` に対応する共通のキャッチコピー・解説（`baseResults`）を定義します。

```json
{
  "questions": [
    {
      "q": "Q1. 飲み会で最初に頼む一杯は？",
      "options": [
        { "text": "とりあえず生ビール！", "type": "01" },
        { "text": "さっぱりレモンサワー", "type": "03" }
      ]
    }
  ],
  "baseResults": {
    "01": {
      "catch": "不動のセンター！頼れる定番リーダー",
      "desc": "周囲への気配りができ、どんな場でも安心感を与える存在です。"
    }
  }
}
```
### 2. `stores.json`（店舗別のメニュー名データ）
6桁の店舗コードごとに、各IDに対応する実際の店舗メニュー名を定義します。

```json
{
  "000000": {
    "01": "名物！鉄板焼き餃子",
    "02": "とろ〜りチーズだし巻き",
    "03": "特製ポテトサラダ"
  },
  "123456": {
    "01": "〇〇店限定 炭火焼き鳥盛り",
    "02": "〇〇店限定 明太もちチーズ"
  }
}
```
## よくあるカスタマイズ

| やりたいこと | 編集箇所 / 手順 |
| :--- | :--- |
| **店舗ごとのメニュー名を追加・変更する** | `stores.json` の該当店舗コード（または `000000`）内のメニュー名を編集 |
| **メニュー画像を追加・差し替える** | `images/000000/`（または `images/店舗コード/`）内に `01.webp`〜`12.webp` を配置 |
| **質問や性格の解説文を変更する** | `data.json` の `questions` や `baseResults` を編集 |
| **トップ画面の画像を変える** | `images/top.webp` を同じファイル名で差し替える |
| **トップボタンの位置を調整する** | `index.html` の `.top-btn-overlay` にある `bottom: 100px;` の数値を調整 |
| **グループ診断の役割分けを変える** | `index.html` の `showGroupResult` 関数内のID配列（`["01", "08", "03"]` 等）を調整 |

## 注意事項

- **ローカル環境（PC直接ダブルクリック）での動作について**
  - `index.html` をブラウザで直接開く（`file://` プロトコル）と、セキュリティ制限（CORS）により `data.json` と `stores.json` の `fetch` 読み込みに失敗し「データの読み込みに失敗しました」と表示されます。
  - 動作確認は **GitHub Pages** や、VS Code の「Live Server」などの Web サーバー経由で行ってください。
- **CSS冒頭の記述について**
  - `index.html` 内の `<style>` 冒頭にある `- { box-sizing: border-box; ... }` は本来全称セレクタ `* { ... }` の記述箇所です。レイアウト崩れを防ぐため、必要に応じて `*` へ修正してご利用ください。
- **画像の拡張子と比率**
  - メニュー画像は `.webp` 形式・正方形（アスペクト比 `1:1`）で統一されています。別拡張子（`.png` / `.jpg`）を使う場合は `getMenuImagePath` 内の拡張子記述も合わせて変更してください。

## メニューID（"01"〜"12"）の性格分類と登録目安

グループ診断では、選択されたメニューIDに応じて「宴会のリーダー」「ムードメーカー」「コース判定」が自動で振り分けられます。店舗ごとのメニューを設定する際は、以下の役割分類を参考に登録してください。

| 分類グループ | 該当ID | グループ診断での役割 | 理想的な登録数・メニュー例 |
| :--- | :--- | :--- | :--- |
| **定番・安定・リーダー系** | `"01"`, `"03"`, `"08"` | 宴会の仕切り役（リーダー）<br>王道宴会コースの判定 | **3品（全3枠登録推奨）**<br>生ビール、枝豆、ポテトサラダ、焼き鳥盛りなど「とりあえず頼む定番」 |
| **熱血・盛り上げ・ムードメーカー系** | `"02"`, `"05"`, `"09"`, `"10"`, `"12"` | ムードメーカー（キーパーソン）<br>ハイテンション爆盛りコースの判定 | **4〜5品（全5枠登録推奨）**<br>唐揚げ、鉄板料理、だし巻き卵、メガジョッキなど「場が盛り上がる看板・ガッツリ系」 |
| **マイペース・癒やし・マニアック系** | `"04"`, `"06"`, `"07"`, `"11"` | 大人ののんびりコースの判定<br>（通好み・マイペース枠） | **3〜4品（全4枠登録推奨）**<br>冷奴、エイヒレ、お新香、締めのお茶漬け・デザートなど「渋め・こだわり・甘味系」 |

- **合計登録数の目安**: **全12品（`"01"`〜`"12"` すべて）** を登録すると、人数入力画面が2列×6行で綺麗に収まり、グループ診断のバランス判定も最も偏りなく機能します。
- **メニュー数を減らしたい場合**: 店舗の品数に合わせて一部のIDを省略することも可能ですが、偏りを防ぐため **各分類グループから最低2品以上（合計6〜8品以上）** 残すことを推奨します。
