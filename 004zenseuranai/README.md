# 前世診断

生年月日と直感的な4つの質問への回答から前世を占う、スマートフォン向けWeb診断コンテンツです。  
タイムトラベル風のフルスクリーン動画演出を経て、前世の称号・イラスト・エピソード・現世への影響、およびURLハッシュの店舗コードに連動したおすすめメニュー（ソウルフード）を表示します。

## フォルダ構成

```text
├── index.html       … 診断本体（設問UI・演出動画制御・診断ロジック・結果表示）
├── menu.json        … 店舗ごとのソウルフード設定ファイル（★ここを編集してメニューを変更）
└── image/           … 画像・動画アセットフォルダ
    ├── background.jpg   … 設問画面の背景画像
    ├── result_bg.jpg    … 結果画面の背景画像
    ├── time-travel.mp4  … タイムスリップ演出用ムービー（全画面再生）
    ├── result1.webp     … 前世イラスト（伝説の騎士）
    ├── result2.webp     … 前世イラスト（江戸のほっこり団子屋）
    ├── result3.webp     … 前世イラスト（カリスマ船長）
    ├── result4.webp     … 前世イラスト（気ままな街の野良猫）
    ├── result5.webp     … 前世イラスト（宮廷の星読み師）
    ├── result6.webp     … 前世イラスト（からくり屋敷の発明家）
    ├── result7.webp     … 前世イラスト（森の長老グマ）
    ├── result8.webp     … 前世イラスト（ヴェネツィアの貴族）
    ├── result9.webp     … 前世イラスト（流れ星の旅人）
    └── result10.webp    … 前世イラスト（古書の街の図書委員長）
```

## 主な機能と仕組み

- **店舗コード（6桁）連動のおすすめメニュー配信**
  - URL末尾のハッシュ（例: `https://.../#123456`）から6桁の店舗コードを取得します。
  - ハッシュがない場合や設定が存在しない店舗の場合は、デフォルト店舗コード `000000` のメニューが自動適用されます。
  - 診断結果インデックス（`0`〜`9`）に対応したメニューが `menu.json` から読み込まれ、「前世あなたが愛したソウルフード」枠に表示されます。

- **生年月日 ＋ ランダム4問による診断ロジック**
  - ① 生年月日（1940年〜2026年のプルダウン選択）
  - ②〜⑤ 全8問の設問プール（`questionPool`）から、プレイごとに4問がランダムにシャッフル抽出されて出題されます。
  - スコアは「生年月日の合計（年+月+日）」と「選択した選択肢の番号（1〜4）の合計」を合算し、全10パターンの結果に剰余計算（`% 10`）で決定されます。同じ生年月日・同じ回答であれば常に同じ結果が導き出されます。

- **タイムスリップ動画演出 (`image/time-travel.mp4`)**
  - 「前世へタイムスリップ！」ボタンを押すと全画面の動画再生画面に切り替わり、ワープ動画が自動再生（ミュート）されます。
  - 動画再生完了（`onended`）で自動的に結果画面へ遷移します。端末環境等で再生が失敗した場合もエラーを検知して即座に結果画面へスキップするフォールバックを備えています。

- **詳細な前世カルテ表示 & リセット機能**
  - 診断結果には「称号」「イラスト」「過去のエピソード」「現世への影響（才能／弱点）」「ソウルフード」が表示されます。
  - 「もう一度診断する」ボタンを押すと、質問プールから新たに別の4問が再抽出されて最初からやり直すことができます。

## よくあるカスタマイズ

| やりたいこと | 編集箇所 / 手順 |
| :--- | :--- |
| **おすすめメニューを変更・追加する** | `menu.json` の該当店舗コード内の `"0"`〜`"9"` のテキストを編集 |
| **新しい店舗を追加する** | `menu.json` に新しい6桁の店舗コードをキーとして追加し、`"0"`〜`"9"` を設定 |
| **診断結果の文面・称号を変更する** | `index.html` 内の配列 `results` の `title`, `story`, `talent`, `weak` を編集 |
| **結果イラストを差し替える** | `image/result1.webp`〜`image/result10.webp` を同じファイル名で差し替える |
| **質問内容・選択肢を変更する** | `index.html` 内の配列 `questionPool` のテキスト（`text`）や選択肢（`options`）を編集 |
| **背景画像・演出動画を変更する** | `image/` フォルダ内の `background.jpg`、`result_bg.jpg`、`time-travel.mp4` を差し替える |

## 注意事項

- **ローカル環境（PC直接ダブルクリック）での動作について**
  - `index.html` をパソコンのブラウザで直接開く（`file://` プロトコル）と、セキュリティ制限（CORS）により `menu.json` の `fetch` 読み込みが失敗します。
  - 動作確認は **GitHub Pages** や、VS Code の「Live Server」などの Web サーバー環境で行ってください。
- **動画ファイル（time-travel.mp4）の容量と自動再生**
  - スマートフォンでの読み込み負荷を抑えるため、演出動画はできる限りファイルサイズを軽量化したMP4形式を推奨します。
  - ブラウザの自動再生ポリシーを満たすため、動画タグには `playsinline muted webkit-playsinline` が指定されています。
- **JSONの構文エラー**
  - `menu.json` を編集する際、末尾の不要なカンマ（`,`）や全角クォーテーションの混入に注意してください。構文エラーがあるとメニューが読み込めず「おすすめメニュー」と代替表示されます。
