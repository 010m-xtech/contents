# まちがい探し

上下に並んだ2枚の写真を見比べて、5つの違い（まちがい）を制限時間45秒以内に見つけ出すスマートフォン向けWebゲームです。  
URLハッシュによる店舗別オリジナル問題の出し分け、上下連動のピンチイン・アウト拡大＆ドラッグ移動（パン）、タイムアップ後の答え合わせモード、Web Audio APIによる効果音生成を備えています。

## フォルダ構成

```text
├── index.html          … ゲーム本体（p5.js描画・ズーム/パン同期・当たり判定・音声生成）
├── stages.json         … 店舗コード別の問題・正解座標データ（★問題追加時はここを編集）
└── image/              … 画像アセットフォルダ
    ├── top.webp        … スタート画面の背景画像
    ├── 000000/         … デフォルト店舗用の問題画像フォルダ（例: stage1_a.webp, stage1_b.webp）
    └── [店舗CD]/       … URLハッシュの店舗コードに対応した個別問題画像フォルダ（任意）
```
## 主な機能と仕組み

- **URLハッシュによる店舗別問題の動的切り替え (`stages.json`)**
  - URL末尾のハッシュ（例: `index.html#123456`）から6桁の店舗コードを取得し、該当店舗専用の問題セットを `stages.json` から読み込みます。
  - ハッシュ未指定または未登録店舗の場合は、デフォルト店舗 `000000` の問題セットが自動適用されます。
  - 同一店舗内に複数の問題（ステージ）が登録されている場合、プレイごと・リトライごとにランダムで異なる問題が選題されます。

- **上下同時連動のピンチ拡大（ズーム）＆ドラッグ移動（パン）**
  - スマホでの2本指ピンチ操作（PCではマウスホイール）により、**最大3.5倍**まで画像を拡大できます。
  - 拡大中の1本指ドラッグ（PCではマウスドラッグ）による表示位置の移動にも対応しており、上の写真と下の写真が常に同じ倍率・同じ位置で連動して動くため、細部までストレスなく見比べることができます。
  - 拡大中は右上に「🔍 全体表示」ボタンが出現し、ワンタップで等倍表示へリセットできます。

- **相対座標による正確な当たり判定とタッチ補正**
  - `stages.json` に定義された相対座標（`0.0`〜`1.0`）をもとに、画面サイズや拡大倍率に関わらず正確な当たり判定を行います。
  - 下の写真をタップして正解すると、上下両方の写真に赤い丸印（○）が同時描画され、ハズレをタップすると白いバツ印（×）エフェクトとブザー音が鳴ります。

- **45秒カウントダウン＆答え合わせモード**
  - 制限時間は45秒（残り10秒以下で赤く点滅警告）。
  - 時間切れになった場合でも、リザルト画面の「答え合わせを見る」ボタンを押すことで、すべての正解箇所に赤丸が表示された状態で確認できます。

- **Web Audio API による内蔵効果音**
  - 外部音声ファイルを使わず、ブラウザの `AudioContext` による合成音声で正解音（correct）、不正解音（miss）、クリアファンファーレ（clear）、タイムアップ音（timeUp）を再生します。

## 設定ファイル（stages.json）の書き方

`index.html` と同じ階層に `stages.json` を配置し、6桁の店舗コードごとに問題配列を定義します。

```json
{
  "000000": [
    {
      "img1": "q1_top.webp",
      "img2": "q1_bottom.webp",
      "diffs": [
        { "x": 0.25, "y": 0.30, "r": 0.07 },
        { "x": 0.50, "y": 0.45, "r": 0.07 },
        { "x": 0.72, "y": 0.22, "r": 0.07 },
        { "x": 0.35, "y": 0.78, "r": 0.07 },
        { "x": 0.80, "y": 0.65, "r": 0.07 }
      ]
    }
  ],
  "123456": [
    {
      "img1": "store_q1_top.webp",
      "img2": "store_q1_bottom.webp",
      "diffs": [
        { "x": 0.20, "y": 0.40, "r": 0.08 }
      ]
    }
  ]
}
```
- `img1` / `img2`: 上画面・下画面に表示する画像ファイル名（`image/[店舗CD]/` 配下に配置）
- `x` / `y`: 画像の左上を `(0.0, 0.0)`、右下を `(1.0, 1.0)` としたときの正解の中心座標（割合）
- `r`: 当たり判定の半径（省略時はデフォルト `0.07` が適用されます）

## よくあるカスタマイズ

| やりたいこと | 編集箇所 / 手順 |
| :--- | :--- |
| **新しい問題・店舗を追加する** | `image/[店舗CD]/` に上下2枚の画像を配置し、`stages.json` に画像名と `diffs` 座標を追記 |
| **制限時間（45秒）を変更する** | `index.html` 内の `const TIME_LIMIT = 45;` および初期表示の `<span id="timer-text">45</span>` を変更 |
| **最大拡大率（3.5倍）を変更する** | `touchmove` および `wheel` イベント内の `Math.min(3.5, ...)` の数値を調整 |
| **当たり判定の広さ（優しさ）を調整する** | `checkTapHit` 内の `* 1.15` の倍率、または `stages.json` の各 `r` の値を大きくする |
| **スタート画面の背景・ボタン位置を変える** | `image/top.webp` を差し替え、必要に応じて `#start-btn` の `top: 47%;` を調整 |

## 注意事項

- **上下2枚の画像サイズ（縦横比）の統一**
  - 上画面（`img1`）と下画面（`img2`）は、**必ず同じ解像度・同じアスペクト比**の画像を用意してください。縦横比が異なると拡大・移動時に座標がズレる原因になります。
- **CSS冒頭の記述について**
  - `index.html` 内の `<style>` 冒頭にある `- { margin: 0; padding: 0; ... }` は本来全称セレクタ `* { ... }` の記述箇所です。余白リセットを有効にするため、必要に応じて `*` へ修正してご利用ください。
- **ローカル環境での動作確認**
  - `stages.json` を `fetch('stages.json')` で読み込んでいるため、PC上でHTMLファイルを直接ダブルクリック（`file://` プロトコル）するとCORS制限によりエラーになります。動作確認は **GitHub Pages** や、VS Code の「Live Server」などの Web サーバー環境で行ってください。
