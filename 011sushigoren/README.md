# 寿司打ち5連

サラリーマンの連続注文を記憶し、注文された順番通りに素早く寿司を握る（タップする）記憶力＆スピード勝負のWebゲームです。  
2連注文からスタートし、ノーミスで5連注文の完答を目指します。Web Audio APIによる効果音生成、ゲージタイマー、表情変化ギミックを搭載しています。

## フォルダ構成

```text
├── index.html       … ゲーム本体（UI・記憶ロジック・音声生成・アニメーション）
└── image/           … ゲーム内で使用する画像アセット
    ├── background.png      … 寿司屋の背景
    ├── background_mae.png  … 手前のカウンター席
    ├── face_straight.png   … 客の通常表情
    ├── face_smile.png      … 客の満足表情（クリア時）
    ├── face_anger.png      … 客の怒り表情（ミス・時間切れ時）
    ├── sushi_maguro.png    … まぐろ
    ├── sushi_samon.png     … サーモン
    ├── sushi_tai.png       … たい
    ├── sushi_tamago.png    … たまご
    ├── sushi_ikura.png     … いくら
    ├── sushi_anago.png     … あなご
    ├── sushi_ebi.png       … えび
    ├── sushi_ika.png       … いか
    └── sushi_kappa.png     … かっぱ巻き
```

## 主な機能と仕組み

- **段階的な記憶チャレンジ（2連〜5連）**
  - 最初は2連（2貫）の注文から開始し、正解するごとに 3連 → 4連 → 5連 と難易度が上がっていきます。
  - 5連の注文をノーミスで握り終えると完全クリアとなります。

- **テンポの良い注文読み上げアニメーション**
  - 客の吹き出しに注文のネタ名が1貫ずつ順番に表示されます（点滅間隔：表示700ms、非表示200ms）。
  - すべての注文が表示し終わると、回答用の寿司ボタン一覧（3×3グリッド）と制限時間バーが出現します。

- **制限時間ゲージとペナルティ**
  - **回答の制限時間**: 2〜3連は4秒、4〜5連は6秒に設定されています。
  - 残り時間に応じてタイムバーが減少し、残り35%以下になるとバーが緑色から赤色に変化します。
  - 時間切れ、または順番・ネタを1つでも間違えた瞬間に即座にゲームオーバーとなります。

- **Web Audio API による内蔵効果音**
  - 外部の音声ファイルを使わず、ブラウザの `AudioContext` による合成音声でタップ音（pop）、正解音（correct）、不正解音（wrong）を生成・再生します。

- **つけ台への寿司配置演出**
  - タップした寿司がリアルタイムに中央の「つけ台（板）」へ並べられ、自分が何貫握ったか視覚的に確認できます。

## よくあるカスタマイズ

| やりたいこと | 編集箇所 / 手順 |
| :--- | :--- |
| **寿司のネタ・画像を変更する** | `index.html` 内の配列 `SUSHI_DATA` の `id` / `name` / `file` を編集 |
| **回答の制限時間を変える** | `updateGameLoop` 関数内の `limitTime = (orderSequence.length <= 3) ? 4000 : 6000;` のミリ秒数（4000/6000）を調整 |
| **最大連数（クリア条件）を変える** | `handleSushiClick` 内の `if (currentLevel >= 5)` を変更（例: `7` にして7連にする） |
| **注文の表示スピードを変える** | `updateGameLoop` 内の `gameTimer >= 700`（表示時間）や `gameTimer >= 200`（非表示時間）を調整 |
| **客の表情画像を変更する** | `image/` 内の `face_straight.png`、`face_smile.png`、`face_anger.png` を差し替え |

## 注意事項

- **音声の再生タイミングについて**
  - ブラウザの自動再生ポリシーにより、画面読み込み直後は音声がミュート状態になります。「開店（スタート）」ボタンを押したタイミングで `audio.init()` が実行され、音声が有効化されます。
- **画像の縦横比と欠損**
  - 寿司画像（`sushi_*.png`）は透過PNGかつ横長（比率おおむね 3:2）を推奨します。画像が見つからない場合はボタン内の文字のみが表示されるフォールバック処理が入っています。
- **モバイル対応（レスポンシブ）**
  - スマートフォンの縦向き画面（最大幅390px、最大高さ844px）に最適化されています。PCブラウザでも中央にスマホ比率で固定表示されます。
