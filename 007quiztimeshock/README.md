# 年代別クイズ TIME SHOCK!

テレビ番組風の緊迫感ある演出とともに、年代別の4択クイズに挑戦できるスマートフォン向けWebゲームです。  
スマホの横向きプレイに特化しており、円形クロックダイヤルによるカウントダウン演出や、出題後の正解・解説の振り返り機能を備えています。

## フォルダ構成

```text
├── index.html       … ゲーム画面本体（UI構造・各画面の切り替えレイアウト）
├── style.css        … スタイルシート（横向きレイアウト・時計ダイヤル・演出エフェクト）
├── app.js           … ゲームロジック（クイズデータ・タイマー制御・正誤判定・演出処理）
└── movie.mp4        … オープニング導入ムービー
```

## 主な機能と仕組み

- **年代別クイズ選択（1980年代〜2010年代）**
  - トップ画面で挑戦したい年代（1980年代 / 1990年代 / 2000年代 / 2010年代）を選択してスタートできます。
  - 各年代に合わせた問題セットが読み込まれます。

- **2つのタイマーモード**
  - **時間制限あり**: 1問あたり10秒、全問合計120秒の制限時間カウントダウン。番組風の緊迫感ある演出を楽しめます。
  - **時間制限なし**: 制限時間を気にせずじっくり考えながら回答できるモードです。

- **円形クロックダイヤル演出 (`#dial`)**
  - 画面左側に時計盤風のダイヤルを配置し、残り時間や現在の正解数（例: 正解: 0/12）を視覚的に表示します。
  - タイムショック特有のフラッシュ演出（`#flash-layer`）や画面割れ演出（`#crack-layer`）に対応しています。

- **導入ムービー & スキップ対応 (`movie.mp4`)**
  - ゲーム開始前にOPムービーが自動再生されます。右上の「SKIP」ボタンで即座にスキップしてホーム画面へ遷移可能です。

- **横向き画面固定推奨**
  - スマホの画面の向きを検知し、縦向き時には「スマホを【横向き】にしてください」のメッセージを表示して横向きプレイを促します。

- **正解・解説の振り返り機能 (`#review-overlay`)**
  - クイズ終了後のリザルト画面から「正解と解説をみる」を選択すると、出題された全問題の正解と解説をスクロール一覧で確認できます。

## よくあるカスタマイズ

| やりたいこと | 編集箇所 / 手順 |
| :--- | :--- |
| **問題や選択肢・解説を変更する** | `app.js` 内の問題データ（JSONや配列）を編集 |
| **制限時間を変更する** | `app.js` 内のタイマー設定（1問あたりの秒数やトータル秒数）の数値を変更 |
| **オープニング動画を変更する** | ルートフォルダの `movie.mp4` を差し替える（または `index.html` の `<video src="...">` を変更） |
| **画面デザイン・フォント色を変更する** | `style.css` 内のカラーコード（例: `#ffc107` など）や配置スタイルを調整 |
| **合格基準（目標正解数）を変更する** | `index.html` の `#era-badge`（「10問正解をめざせ！」）および `app.js` 内の判定ロジックを調整 |

## 注意事項

- **動画（movie.mp4）の自動再生について**
  - スマートフォンや一部ブラウザでは、音声付きの動画自動再生がブロックされる仕様があります。本コードでは `muted playsinline autoplay` を指定して対策していますが、ファイル差し替え時は容量の肥大化による読み込み遅延にご注意ください。
- **外部ファイルの配置**
  - `style.css`、`app.js`、`movie.mp4` が `index.html` と同じ階層（ルートディレクトリ）に存在しないとスタイルやゲームロジックが正常に読み込まれません。
- **ローカル環境での動作確認**
  - `index.html` を直接ダブルクリックしてブラウザで開く（`file://` プロトコル）と、`app.js` 側で問題データを外部読み込み（fetch等）している場合にCORSエラーで止まることがあります。動作確認は **GitHub Pages** やローカルWebサーバー環境で行ってください。
