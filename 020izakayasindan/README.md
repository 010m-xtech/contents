# メニュー性格診断

いくつかの質問に答えることで、自分の性格を居酒屋のメニューに例えて診断できるスマートフォン向けWebコンテンツです。  
個人診断の結果から、テーブルにいるメンバー全員の診断結果を合算する「2人用相性診断」「3人以上グループ診断」へ展開でき、店舗コードに応じたおすすめメニューの注文促進（プロモーション表示）まで一連の流れで楽しめます。

## フォルダ構成

```text
├── index.html          … 診断本体（UI・質問進行・個人/ペア/グループ診断ロジック）
├── data.json           … 質問データおよび共通の性格タイプ解説データ
├── stores.json         … 店舗コード別のメニュー名マッピングデータ（★店舗ごとに編集）
└── images/             … 画像アセットフォルダ
    ├── top.webp        … トップ画面のメインビジュアル画像
    ├── 000000/         … デフォルト店舗用のメニュー画像フォルダ（01.webp 〜 12.webp）
    └── [店舗CD]/       … URLハッシュの店舗コードに対応した個別メニュー画像フォルダ（任意）
```
## 主な機能と仕組み

- **URLハッシュによる店舗別メニュー＆画像の動的切り替え**
  - URL末尾のハッシュ（例: `index.html#123456`）から6桁の店舗コードを取得します。
  - `stores.json` に該当店舗のメニューが定義されていればそのメニュー名を表示し、未指定・未登録の場合はデフォルト店舗 `000000` が自動適用されます。
  - メニュー画像は `images/[店舗CD]/[メニューID].webp` を読み込み、個別画像が存在しない場合は `images/000000/[メニューID].webp` へ自動フォールバックします。

- **個人性格診断（メニュー診断）**
  - `data.json` に定義された質問に回答し、各選択肢に紐づくタイプ別スコアを加算して最もスコアの高いメニュー（同点時はランダム抽選）を結果として表示します。
  - 結果画面にはメニュー画像・キャッチコピー・性格解説のほか、テーブルでの注文を促すプロモーション枠が表示されます。

- **テーブルメンバー合算（ペア診断 ＆ グループ診断）**
  - 個人診断後に「今日のグループ診断を作成」からテーブル上の各メニューの人数を入力できます（自分の結果は初期値1名として自動セット）。
  - **2名の場合（ペア診断）**: 2人の相性度（%アニメーション表示）、関係性分析、ワンポイントアドバイスを表示します。
  - **3名以上の場合（グループ診断）**: メンバーの構成比率（熱血・安定・マイペース系）に応じて宴会コース名・チームワーク度・リーダー役・ムードメーカー・ベスト相性コンビ・取扱説明書を自動生成します。

## 設定ファイル（data.json / stores.json）の書き方

### 1. `data.json`（質問と性格タイプのベースデータ）
質問リスト（`questions`）と、ID `"01"`〜`"12"` に対応する共通のキャッチコピー・解説（`baseResults`）を定義します。

```json
{
  "questions": [
    {
      "q": "Q1. 飲み会で最初に頼む一杯は？",
      "options": [
        { "text": "とりあえず生ビール！", "type": "01" },
        { "text": "さっぱりレモンサワー", "type": "03" }
      ]
    }
  ],
  "baseResults": {
    "01": {
      "catch": "不動のセンター！頼れる定番リーダー",
      "desc": "周囲への気配りができ、どんな場でも安心感を与える存在です。"
    }
  }
}
