# sakesindan_v2（お酒診断・管理しやすい版）

```
sakesindan_v2/
├── index.html   … 仕組み（見た目・動き）。通常は触らない
├── menu.json    … 文言・画像・質問・タイプ・おすすめ商品（★ここだけ編集）
└── image/       … 画像・背景動画を置く場所
```

## よくある変更

| やりたいこと | 編集する場所 |
|---|---|
| 商品名・産地・飲み方・商品写真を変える | `menu.json` の `menu` |
| お酒の種類（ワイン/日本酒/クラフト酒）の名前・画像 | `drinks` |
| 質問文・選択肢・選択肢の画像 | `questions` |
| タイプ名・説明・レーダーチャート | `types` |
| オープニング文・タイトル・背景動画・GASのURL | `settings` |

### 画像の入れ替え
1. 画像を `image/` フォルダにアップロード
2. `menu.json` の `"img": "ファイル名.jpg"` を書き換える

`image/` は自動で付くので、ファイル名だけ書けばOK。

### 商品（menu）
`type`（タイプ）× `drink`（お酒の種類）の組み合わせで1件。

```json
{ "type": "type1", "drink": "sake", "name": "〇〇 特別純米", "origin": "山口県", "howTo": "冷やで\nお刺身と", "img": "sarasara_sake.jpg" }
```

- 今は元のページと同じく、すべて「仮のテキスト」が入っています。商品が決まったら書き換えてください
- `img` を空 `""` のままにすると「DRINK PHOTO」と表示されます
- 改行は `\n`

### 質問（questions）
- `points` … 選んだときに各タイプへ入る点数。合計が一番高いタイプが結果（同点は `types` の上にあるほう）
- `imgText` … 画像の代わりに大きな文字を表示（例: `UNDER35`）
- `sendAs` … スプレッドシートに送る項目名（GAS側と合わせる。`q1Gender` / `q2Age`）
- 質問を増やす・減らすと、トップの「〇つの質問」も自動で変わります

## 注意
- JSONは **最後の項目の後ろにカンマを付けない**、**文字は `"` で囲む**。間違えると画面にエラー内容が出ます
- `index.html` をパソコンで直接ダブルクリックすると `menu.json` を読めません。GitHub Pages 等のURLで確認してください
