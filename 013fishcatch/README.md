# お魚キャッチ

奥から投げられる魚などの海の生き物を左右移動でキャッチしていく、スマートフォン向けの30秒カジュアルキャッチゲームです。  
店舗コードに応じたプレイヤー画像の動的切り替え、時間経過によるスピードアップ演出、ハイスコアのローカル保存、Web Audio APIによる効果音生成、Google Apps Script（GAS）へのアクセス解析ログ送信機能を備えています。

## フォルダ構成

```text
├── index.html       … ゲーム本体（UI・p5.js描画・物理演算・音声生成・ログ送信）
└── image/           … ゲーム内で使用する画像アセット
    ├── top.webp         … タイトル画面の背景画像
    ├── end.webp         … リザルト画面の背景画像
    ├── background.webp  … プレイ中の背景画像
    ├── 000000.png       … デフォルトのプレイヤー画像
    ├── [店舗CD].png     … 店舗別オリジナルプレイヤー画像（任意）
    ├── fugu.png         … フグ
    ├── ika.png          … イカ
    ├── kani.png         … カニ
    ├── sakana.png       … 魚
    ├── sakanamini.png   … 小魚
    └── tako.png         … タコ
```

## 主な機能と仕組み

- **直感的なスライド操作 & キーボード操作**
  - スマホの画面タッチ・スワイプでプレイヤーが左右にスムーズに追従します。
  - PCブラウザでの確認用に「A / Dキー」および「左右矢印キー」での移動にも対応しています。

- **店舗コード連動のプレイヤー画像切り替え**
  - URL末尾のハッシュ（例: `index.html#123456`）から6桁の店舗コードを取得し、該当する `image/123456.png` をプレイヤー画像として動的に読み込みます。
  - ハッシュ未指定時や該当ファイルが存在しない場合は、デフォルト画像 `image/000000.png` が使用されます。画像未配置時でも絵文字（🐱）で動作するフォールバックを備えています。

- **30秒の制限時間と段階的な難易度変化**
  - **通常フェーズ（30秒〜21秒）**: 魚の出現間隔 700ms
  - **スピードアップ（残り20秒〜11秒）**: 「スピードアップ！」のアナウンスとともに魚の出現間隔が 450ms に加速
  - **ラストスパート（残り10秒〜0秒）**: 「ラストスパート！」のアナウンスとともに魚の出現間隔が 280ms に加速し、タイマー表示が赤く点滅

- **放物線による魚の投擲物理演算**
  - 画面奥の投擲位置から手前のプレイヤーの足元に向けて、重力加速度を考慮した放物線軌道で魚がランダムに飛来します。
  - キャッチ成功時は星パーティクル＋上昇和音SE、落下ミス時は土煙パーティクル＋低音SEが発生します。

- **Web Audio API による内蔵効果音**
  - 外部の音声ファイルを使わず、ブラウザの `AudioContext` による合成音声で投擲音（throw）、キャッチ音（catch）、ミス音（miss）、終了ファンファーレ（finish）を再生します。

- **ハイスコア保存 & GASアクセスログ連携**
  - 過去の最高キャッチ数を端末の `localStorage`（キー: `catch_highscore`）に記録し、タイトル画面とリザルト画面に王冠バッジで表示します。
  - ゲーム開始時と終了時に、店舗コード・端末ID・キャッチ数を含めたアクセスログをGASへ送信します。

## よくあるカスタマイズ

| やりたいこと | 編集箇所 / 手順 |
| :--- | :--- |
| **プレイヤー画像を変更・追加する** | `image/` 内に `000000.png` や `店舗コード.png` を配置（横幅110px基準で縦横比自動維持） |
| **魚の種類や画像を変更する** | `image/` 内の各PNG画像を差し替え、スクリプト内の配列 `fishKeys` を編集 |
| **ゲームの制限時間を変える** | スクリプト上部の `const TOTAL_TIME = 30;` の秒数を変更 |
| **魚の出現頻度（難易度）を調整する** | `updateLogic` 内の `interval`（現在700ms / 450ms / 280ms）の数値を調整 |
| **背景画像を変更する** | `image/top.webp`（タイトル）、`image/end.webp`（リザルト）、`image/background.webp`（プレイ中）を差し替え |
| **ログ送信先のGASを変更する** | スクリプト上部の `const GAS_URL = "..."` を新しいウェブアプリURLに差し替え |

## 注意事項

- **音声の初回再生について**
  - ブラウザの自動再生制限により、ページ読み込み直後は音声が無効化されています。「スタート」ボタンをタップした瞬間に `audio.init()` が実行されて音声が鳴るようになります。
- **画像の縦横比について**
  - 背景画像（`top.webp` / `end.webp` / `background.webp`）は、スマートフォンの一般的な縦長比率（アスペクト比 `1125:2436` / 約 `9:19.5`）を推奨します。
  - 各魚の画像（`*.png`）は透過PNG形式で作成してください。
- **画面表示と動作確認**
  - 画面最大幅540pxの縦長スマホ比率に自動スケーリングされます。PCブラウザで直接ファイルを開いても中央にスマホ画面枠で表示されます。
